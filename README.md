# Telegram Chatbot using GPT-3.5 Turbo (telebot_GPT3.5_Turbo_DSM)

## 📌 Project Overview
This project implements an AI-powered **Telegram chatbot** using **OpenAI’s GPT-3.5 Turbo API** and **Python**, with **Aiogram Dispatcher** for efficient asynchronous message handling. The bot is designed for **real-time AI-driven conversations**, ensuring seamless automation and intelligent interactions.

---

## 🚀 Features
- **Real-time AI Conversations**: Utilizes OpenAI’s GPT-3.5 Turbo for intelligent responses.
- **Asynchronous Message Handling**: Uses **Aiogram Dispatcher** for optimized request processing.
- **Modular & Scalable Design**: Built using **OOP principles**, making it easy to extend.
- **Secure API Integration**: Implements environment variables for managing API keys safely.
- **Fast & Efficient**: Handles high message loads with **Aiogram’s event-driven** approach.

---

## 🛠️ Tech Stack
- **Programming Language**: Python  
- **APIs**: OpenAI API, Telegram Bot API  
- **Libraries**: `aiogram`, `openai`, `dotenv`, `requests`  
- **Framework**: Aiogram (async Telegram bot handling)  
- **Deployment**: Local system / Cloud VM / Docker (optional)

---

## 🔑 Prerequisites
Ensure you have the following before running the chatbot:
- Python **3.7+**
- A **Telegram account** and a bot token from **@BotFather**
- **OpenAI API key** for GPT-3.5 Turbo
